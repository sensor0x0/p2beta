Portal 2 Beta Library

A collection of playable Portal 2 beta and pre-release builds, taken from the Steam2 Content Server Dump.

Info

Some builds are ready-to-play repacks by members of the community, whereas some that required manually adding patches, I have added for you, alongside some Start.bat files :)

All of these files are playable directly by launching using the Start.bat or Start.sh file in the folder.

Small warning: These betas are either extremely prone to crashing, or may not crash at all on your system. Make sure you save your progress often.

Big warning: Multiplayer has remote code execution (RCE) vulnerabilities. It is HIGHLY recommended you either don't use it, or only play with people you know, and trust.

How to play

Download the game. Extract it.

If there is a "steam_appid.txt" file, make sure it is set to "480".

Windows: Run Start.bat, if missing you can make one.

Linux: Short guide.
